# 적자생존.

적어야 살아남는다. 교사 개인용 학생 상담 기록 도구입니다.

**Windows 10/11 x64 · Mac M 시리즈**용 데스크톱 앱입니다. 브라우저 주소 입력이나 Node.js 설치 없이 실행할 수 있습니다.

## 프로그램 받기

[최신 버전 다운로드](https://github.com/cheetamin/jeokja-saengjon/releases)

`Code → Download ZIP`은 개발용 소스입니다. 일반 사용자는 **Releases의 실행 파일 ZIP**을 받으세요.

| 컴퓨터 | 받을 파일 |
| --- | --- |
| Windows 10/11, Intel/AMD 64비트 | `JeokjaSaengjon-Setup-0.1.6.exe` |
| Mac M1/M2/M3/M4/M5 등 | `JeokjaSaengjon-Mac-M1-0.1.6.zip` |

## Windows에서 시작하기

1. Windows ZIP을 내려받고 **모두 압축 풀기**를 선택합니다.
2. 압축을 푼 폴더의 **Install.cmd**를 더블클릭합니다.
3. 설치 후 바탕화면 **적자생존** 아이콘으로 실행합니다.
4. 12자 이상 보관함 비밀번호 생성 → 설정 → **가상 학생 3명 등록**으로 시험합니다.

설치 스크립트는 관리자 권한 없이 현재 사용자 폴더에 앱과 바로가기를 만듭니다. 조직에서 스크립트 실행을 제한하는 경우 관리자의 정책을 따라 주세요. 스크립트를 사용할 수 없다면 압축을 푼 `app/JeokjaSaengjon.exe`로 실행할 수 있습니다. EXE만 따로 옮기지 마세요.

Windows 코드 서명 인증서가 없는 시험 버전입니다. 보안 경고가 표시될 수 있으며 조직의 보안 정책을 임의로 해제하지 마세요.

## Mac에서 시작하기

ZIP 압축 해제 → 새 `JeokjaSaengjon.app` 실행. 표시 이름은 적자생존일 수 있습니다. 내부 실행 파일명은 변경하지 마세요. Apple Developer ID 서명·공증은 없으며 ad-hoc 서명된 확인용 패키지입니다. macOS 실행 차단 시 출처를 확인한 뒤 시스템 설정의 개인정보 보호 및 보안에서 해당 앱 실행 여부를 선택합니다.

## 기능

- 학생 명단 직접 등록, Excel/CSV 미리보기 및 등록
- 상담 일자·교시·시간·대상·제목·내용 기록, Ctrl+S 또는 Command+S
- 암호화 저장, 작성 중 초안, 검색·수정·휴지통·복원
- 학생 ID로 기록 연결, 학년도 구분, 후속 지도 기록
- 교사가 검토한 가명 내용만 승인 후 게시
- 원본 나이스 서식을 보존한 XLSX 생성
- 암호화 백업·복원, 보관함 잠금
- 승인된 Google Workspace 설정 후 별도 스프레드시트 3개에 동기화

## 자료와 Google 연결

상담 자료는 각 컴퓨터의 사용자 데이터 폴더에 암호화하여 저장합니다. **이 GitHub 저장소에는 교사의 상담 기록이 올라가지 않습니다.** 보관함 파일, 토큰 및 실제 학생 명단을 GitHub에 업로드하지 마세요.

Google 연결 전에는 로컬 모드입니다. 연결하려면 선택한 개인 Gmail 또는 학교 Workspace 계정, Google Cloud의 데스크톱 OAuth 클라이언트 및 API 설정이 필요합니다. 설정에서 계정 종류를 명시적으로 선택하고 이메일을 저장해야 합니다. 이 앱이 개인 계정의 실제 학생 자료 저장 적합성을 승인하는 것은 아닙니다. A 실명 원문 / B 교사 승인 가명 / C 나이스 분류 확인 기록을 각각 별도 파일로 관리합니다. 승인되지 않은 원문은 B로 전송하지 않습니다. 자동 비식별 처리는 완전한 익명화를 보장하지 않습니다.

실제 학생 자료 입력 전에 학교·교육청 지침과 저장 환경 승인을 확인하세요. 백업 비밀번호는 복구할 수 없습니다. 나이스 XLSX는 암호화되지 않은 파일입니다.

## 개발자 실행

Node.js 설치 환경에서:

```sh
npm ci
npm run build
npm test
npm start
```

실행 파일 패키징:

```sh
npm run pack:win
npm run pack:mac
```

운영 패키지에는 소스 빌드 외에 플랫폼별 서명·공증 및 실기기 검수가 필요합니다. 자동 업데이트 기능은 없습니다.


## 0.1.6 변경
검정 네모 배경을 제거한 투명 글자 아이콘을 적용했습니다. 개인 Gmail 모드를 추가했고 Google 연결 설정 저장 버튼·준비 상태 안내를 넣었습니다. 실제 Google 로그인·3종 시트 전송은 개인 OAuth 설정 후 별도 확인이 필요합니다. [개인 Gmail 연결 안내](docs/PERSONAL_GMAIL.md)를 참고하세요.


0.1.6에서는 학생 명단 엑셀 양식을 앱에서 내려받고, 공동 지도에 여러 학생을 선택할 수 있습니다. 학생별 조회는 각 참여자 ID를 사용하며, 저장·동기화·내보내기는 공통 상담 ID 한 건을 유지합니다. 업데이트 전에 암호화 백업을 저장하세요. 새 보관함은 이전 버전 앱에서 열 수 없습니다.


0.1.6는 학생 검색 결과를 클릭 가능한 목록으로 표시하고 이름·번호·초성 검색을 개선합니다. 각 교시 쉬는 시간과 점심·방과후 시각을 학교별 시간표에서 지정할 수 있습니다. 기존 시간표는 유지되므로 새 항목의 예시 시각을 확인한 후 저장하세요.


## 앱 내 업데이트
Windows는 Setup.exe를 한 번 설치한 뒤 설정 → 프로그램 업데이트에서 확인·다운로드·재시작 적용을 사용합니다. 기존 ZIP 설치본은 자동 교체용 설치 정보가 없어 Setup 설치가 필요합니다. Mac 현재 빌드는 정식 개발자 서명이 없어 자동 교체를 차단하고 확인·수동 다운로드를 제공합니다. 정식 Mac 서명 및 공증 워크플로는 준비되어 있으며 실제 인증서 설정 후 검증이 필요합니다. 자세한 내용은 [업데이트 안내](docs/AUTO_UPDATE.md)를 참고하세요.


## 다른 선생님 Google 연결 안내
설정의 **Google 연결 시작 · 쉬운 안내**에서 본인 계정 저장, 인증 JSON 준비, 로그인과 가상 기록 확인을 순서대로 안내합니다. [처음 시작하기](docs/GOOGLE_START_HERE.md)를 함께 배포할 수 있습니다. 공통 인증 파일을 모든 선생님에게 공유하는 방식이 아니며, 각 계정의 최초 Google 설정은 필요합니다.
