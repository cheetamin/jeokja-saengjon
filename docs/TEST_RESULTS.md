## 발견하여 수정한 사항
- Google 네트워크 작업과 로컬 저장 큐 분리. 잠금/연결 해제 시 진행 중 전송 취소, 버전 일치 여부 확인 후 상태 반영.
- 저장 중 폼 입력 고정 및 중복 저장 방지. 다른 기록 편집 전 초안 폐기 확인.
- 원격 관리 ID가 없는 데이터 행을 충돌로 차단. 삭제 완료로 오인하지 않음.
- 파일 생성 작업 식별자를 먼저 저장. 응답이 유실되면 검색·확인 대기로 전환.
- Google 파일 소유자 식별을 로그인 상태와 분리해 계정 변경 시 다른 파일 매핑 적용.
- 백업 스키마/ID 검증, 복원 직전 별도 복구 사본 보존.
- 가명 방식과 추가 가림 목록 변경 시 기존 승인 해제.
- 운영 의존성의 알려진 취약점이 발견된 구버전을 교체.
