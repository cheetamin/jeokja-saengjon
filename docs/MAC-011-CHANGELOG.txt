적자생존 Mac Apple Silicon 0.1.1 — 보조 실행 파일 경로 수정 빌드

1. 이전 앱과 오류 보고서 창을 닫습니다.
2. 이 ZIP을 새 폴더에 압축 해제합니다.
3. 새 폴더의 JeokjaSaengjon.app을 실행합니다. Finder에서는 표시 이름이 '적자생존'으로 보일 수도 있습니다.
   이전 Dock 아이콘이나 이전 폴더의 앱은 실행하지 마세요.
4. Apple 공증 미확인 경고는 시스템 설정 → 개인정보 보호 및 보안 → 해당 앱 '확인 없이 열기'에서 실행 여부를 선택합니다.
5. 정상적으로 열리면 가상 학생으로 먼저 확인합니다.

터미널 재서명 명령을 실행하거나 앱 파일 이름을 변경하지 마세요.
내부 실행 이름은 영문이며 화면 제목은 '적자생존.'입니다.
기존 사용자 데이터 저장 위치를 유지합니다. 기존 자료 삭제 작업은 없습니다.
새 버전은 0.1.1입니다. 다시 충돌 보고서가 나오면 Version이 0.1.1인지 확인하세요.

수정 내용:
- 본체·보조 실행 파일 이름을 모두 ASCII로 통일.
- CFBundleName과 CFBundleExecutable의 한글 정규화 차이 제거.
- 앱 및 내부 실행 파일에 ad-hoc 서명과 JIT 권한 적용.
- 상담 저장·조회 및 자료 형식은 변경 없음.

검증:
- 보고서 UUID와 공식 Electron 45.3.2 ARM64 심볼 일치.
- 충돌 함수: ElectronBrowserClient::AppendExtraCommandLineSwitches.
- 호출 경로: GpuProcessHost::LaunchGpuProcess → 보조 실행 경로 검사.
- 본체와 보조 실행 경로 5개 정적 검사 통과.
- 기존 자동 테스트 20/20 통과.
- 코드 페이지 및 실행 권한의 서명 해시 검사 통과.
실제 맥북 실행과 현재 충돌 해결 여부는 아직 미확인입니다.
Apple Developer ID 서명·공증은 완료하지 않았습니다.
