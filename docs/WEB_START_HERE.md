# 웹에서도 적자생존 사용하기 — 0.1.7

웹 주소: https://jeokja-counsel-web-20261118.workspace-889499.chatgpt.site

웹 주소는 앱 설정 → 웹 주소 복사에서 복사할 수 있습니다. 누구나 로그인 없이 웹을 열고 이 브라우저에 암호화하여 기록할 수 있습니다. 로그인 없이 만든 보관함을 다른 기기에서 사용하려면 웹 암호화 백업을 내려받고 다른 브라우저에서 복원하세요. 아래 로그인 절차는 기존 웹·앱 자동 동기화를 사용할 때만 필요합니다. 실제 학생 정보를 전송하기 전 소속 기관이 이 저장 환경을 허용하는지 확인하세요. 학교·교육청의 승인을 받았다고 프로그램이 대신 보증하지 않습니다.

## 처음 한 번

1. 웹 주소를 열고 ChatGPT 계정으로 로그인합니다. Google Sheets 연결에 쓰는 Google 로그인과는 별개입니다.
2. 웹 보관함 비밀번호를 12자 이상으로 만듭니다. 긴 문장을 권장합니다. 복구할 수 없으므로 별도로 보관하세요.
3. 우선 설정 → 가상 학생 3명 등록을 누릅니다. 학생을 선택하고 가상 상담을 저장합니다.
4. 화면 위 **웹 보관함: 동기화 완료**를 확인합니다. 저장 성공 안내는 이 브라우저의 암호화 저장 성공을 뜻합니다. 서버 전송 성공은 위 동기화 상태로 별도 확인합니다.
5. 기록 조회에서 확인합니다. 다시 열 때도 같은 비밀번호를 입력하면 이어 볼 수 있습니다.

웹은 학생 명단 엑셀 다운로드/미리보기/등록, 여러 학생 공동 지도, 날짜·교시, 상담 수정·휴지통·복원, 비식별 검토, 나이스 엑셀 생성, 웹 암호화 백업을 지원합니다. 실제 나이스 업로드 성공까지 검증한 것은 아닙니다.

## 기존 앱과 이어 쓰기

1. 기존 앱에서 먼저 **암호화 백업 저장**을 합니다. 기존 보관함 파일을 삭제하거나 다른 폴더로 옮길 필요가 없습니다.
2. 앱을 0.1.7 이상으로 업데이트합니다. Windows 설치판은 설정 → 업데이트 확인을 사용합니다. Mac 미서명 시험판은 새 파일 설치가 필요합니다.
3. 앱의 설정 → **웹 · 앱 자동 동기화** → **웹 보관함 열기**를 누릅니다.
4. 별도로 뜨는 로그인 창에서 웹과 **같은 ChatGPT 계정**으로 로그인합니다. 로그인 창에는 로컬 보관함 접근 권한이나 Google 토큰을 주지 않습니다.
5. 앱 설정으로 돌아와 **웹에서 만든 보관함 비밀번호**를 입력합니다. 기존 컴퓨터 보관함 비밀번호와 달라도 됩니다.
6. 전송 대상 안내와 저장 환경 확인란을 읽고 체크한 뒤 **웹 보관함 연결**을 누릅니다. 현재 명단과 기록, 휴지통이 합쳐집니다. 같은 학급을 두 기기에서 각각 새로 등록했다면 번호 중복이 생길 수 있으므로 한쪽에서 등록 후 동기화하세요.
7. 연결이 완료되면 로그인 창은 숨겨집니다. 앱과 웹이 열려 있고 잠금이 해제된 동안 약 30초마다 변경 사항을 확인합니다. **지금 동기화**로 즉시 시도할 수도 있습니다.

앱은 웹 비밀번호와 동기화 기준을 기존 암호화 보관함 안에 저장하여 다음 잠금 해제 후 자동으로 다시 연결합니다. 화면과 백업 파일에는 이 연결 비밀번호를 포함하지 않습니다. 자동 동기화 중지를 누르면 해당 컴퓨터의 웹 로그인 세션과 연결 정보를 해제합니다. 웹 자료 자체를 삭제하지 않습니다.

## Google Sheets 3종과의 관계

웹에서 적은 기록은 암호화 웹 보관함에 저장됩니다. Google에 연결된 데스크톱 앱을 열면 웹 기록을 받아 기존 Google Sheets 3종 동기화를 이어 갑니다. **앱이 꺼져 있으면 Google Sheets 반영은 기다립니다.** 웹 보관함 동기화 완료가 Google 3종 완료를 뜻하지 않습니다.

Google OAuth 파일·접근/갱신 토큰은 웹으로 전송하지 않습니다. 기존 앱의 Google 연결을 그대로 사용합니다. 가명 기록은 해당 버전의 검토 승인이 필요하고, 나이스 기록은 필수 공식 분류 확인이 필요합니다. 미확인 자료는 자동 게시하지 않습니다.

## 오류와 충돌

- 인터넷이 끊겨도 이미 열어 둔 웹에서는 이 브라우저에 암호화 저장합니다. 연결이 돌아오면 다시 시도합니다. 첫 접속과 페이지를 새로 열 때는 로그인·서버 연결이 필요합니다.
- **동기화 실패**이면 입력 내용을 지우지 말고 연결을 확인해 재시도합니다. 동기화가 끝나기 전에 브라우저 저장 공간을 지우거나 시크릿 창을 종료하면 서버에 전송되지 않은 자료를 잃을 수 있습니다.
- 두 곳에서 같은 기록을 바꾸면 자동 덮어쓰기하지 않습니다. 설정에서 **이 기기 내용 / 웹 보관함 내용**을 비교하고 남길 내용을 선택합니다. 선택 후 기록 ID는 유지하고 비식별 검토는 다시 받습니다.
- 삭제는 휴지통 상태로 동기화되며 복원도 같은 ID로 반영됩니다.
- 웹 암호화 백업은 `.jjweb`, 기존 앱 백업은 `.jjvault`입니다. 서로 다른 포맷이므로 해당 환경에서 복원합니다. 웹 백업 복원 뒤 다른 기기와 내용이 다르면 충돌 확인이 필요합니다.

## 보안 및 운영 범위

서버는 사용자별 암호화 파일만 저장합니다. 암호화는 PBKDF2-SHA256(310,000회), AES-256-GCM과 매 저장마다 다른 IV를 사용합니다. 교사의 명단·기록·일부 공통 설정만 동기화하며 작성 중인 초안은 각 기기에만 남습니다. 교사별 서버 경로를 인증된 사용자 ID에서 계산하고 요청받은 임의 사용자 ID로 접근하지 않습니다. 동시 저장은 R2 조건부 쓰기로 검증합니다.

웹 보관함은 2MB 정도의 원문까지 수용할 수 있는 크기 제한을 둡니다. 한도에 걸리면 실패 상태를 표시하고 원본을 유지합니다. 큰 보관함은 앱 암호화 백업을 사용하세요. 자동으로 오래된 기록을 버리거나 축약하지 않습니다.

공유 컴퓨터에서는 잠금과 로그아웃을 하세요. 브라우저 비밀번호 자동 저장은 사용하지 마세요. 웹 전송 전 암호화가 모든 개인정보 처리 요건을 충족한다는 뜻은 아닙니다. 실제 저장 지역·승인 환경·학교 지침 확인은 별도입니다.

## 검증 범위

가상 자료로 공통 엔진·인증 경계·암호화·조건부 쓰기 및 데스크톱 IPC 연동을 자동 시험했습니다. 브라우저 화면에서 입력·저장·검색·재접속 후 조회도 확인했습니다. 실제 사용자 계정의 ChatGPT 로그인과 두 실물 컴퓨터 사이의 통신, 실제 Google Sheets 쓰기는 사용자 계정에서 최종 확인이 필요합니다. 시험을 실제 학생 정보로 수행하지 않았습니다.
