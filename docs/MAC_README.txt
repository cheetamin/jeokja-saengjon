적자생존 — Mac 확인용 0.1.0

1. Apple 메뉴 → 이 Mac에 관하여에서 칩/프로세서를 확인합니다.
   Apple M 시리즈: AppleSilicon 파일 / Intel: Intel 파일
2. ZIP을 더블클릭해 압축을 풉니다.
3. 적자생존.app을 응용 프로그램 폴더로 드래그합니다.
4. 앱을 더블클릭합니다. Dock에 고정하거나 Finder에서 별칭을 만들어 바탕화면에 둘 수 있습니다.
5. 12자 이상 비밀번호 생성 → 설정 → 가상 학생 3명 등록 → 기록하기에서 시험합니다.
   저장 단축키는 Command+S 또는 Control+S입니다.

이 패키지는 Apple Developer 서명·공증을 받지 않은 확인용 빌드입니다.
실행이 차단된 경우 출처와 파일을 확인한 뒤, 실행을 선택하려면
시스템 설정 → 개인정보 보호 및 보안 → 해당 앱의 '확인 없이 열기'를 이용할 수 있습니다.
조직에서 차단한 경우 관리자에게 확인하세요. 보안 기능 전체를 끄지 마세요.
'손상됨', '악성 소프트웨어' 등 다른 경고가 나오면 해당 문구를 그대로 알려주세요.
Apple 안내: https://support.apple.com/ko-kr/102445

기록은 이 Mac에 암호화하여 저장됩니다:
~/Library/Application Support/JeokjaSaengjon/records.jjvault
Windows에 저장한 기록과 자동으로 합쳐지지 않습니다.
자료 이동이 필요하면 앱의 암호화 백업·복원 기능을 이용하세요.
Google 연결 전에는 전송하지 않습니다. 승인된 Workspace 계정과 OAuth 설정이 필요합니다.
