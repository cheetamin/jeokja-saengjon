# 적자생존 1차 구현 계획
사용자 상세 제작 요청을 설계 기준으로 삼음. 중간 승인 없이 직접 제작 요청에 따라 구현 진행.
선택: Electron + React/TypeScript/Vite. PWA는 설치 및 창 크기 제어 제약, Tauri는 Windows 빌드 도구 의존성. Electron ZIP에 사용자별 설치 스크립트와 바로가기 제공. 외부 공개 배포 없음.
1. 도메인/저장: 고유 ID, 수정 revision, 가명 승인 무효화, AES-GCM 비밀번호 보관함, 원자 파일 쓰기. 테스트: 중복/삭제복원/암호 오류/재개.
2. React 화면: 540px 기록창, 확장 조회, 설정/명단 미리보기/초안. 테스트: 입력 CRUD, 검색, 작은 화면.
3. Google: 데스크톱 OAuth PKCE + loopback, 승인 계정 확인, drive.file 범위, 연도별 3개 파일, ID 기반 동기화, 사본 수동 수정 충돌 차단. 실제 계정 승인은 제공되지 않았으므로 모의 API 테스트와 연결 절차 제공.
4. 나이스: 원본 ZIP 내부 입력 sheetData만 교체하여 참조·이름·확장 유효성 원본 보존. 별도 Google C 파일은 16열 입력 및 참조, ID 관리용 숨김 시트. 테스트: 원본과 나머지 ZIP 항목 동일 및 행 검증.
5. Windows x64 패키지, 설치/삭제 스크립트, 사용 설명서, 기능별 검증 기록. Windows 실제 OS 시험은 이 Linux 환경에서 불가하므로 별도 표시.
검토 중점: 암호 오류 후 덮어쓰기 금지, 저장 실패 시 초안 보존, 승인 후 내용 수정 시 가명 사본 철회, API 응답 유실 후 중복 방지, 엑셀 수식 주입 방지.

완료 기록: 로컬 데이터/React UI/Google 모듈/나이스 XLSX/Windows 패키지 및 설명서 생성. 최종 자동 테스트 20/20 통과.
주요 선택과 한계: 소유자 전용 공유 검사로 가명 파일의 추가 교사 공유도 현재 자동 동기화에서는 차단. Google 실계정 및 Windows native GUI 미검증. 운영 원격 파일 수정 자동 병합 대신 충돌 중단. 보존 기간은 검토 안내이며 자동 영구 삭제하지 않음.
독립 코드 검토의 주요 데이터 유실·충돌·인증 매핑·복원 검증 지적은 수정. 테스트로 원격 관리 행 손상, 생성 응답 유실, 지연 중 로컬 저장, 초안 덮어쓰기 경고 및 복원 오류 방어 확인.
