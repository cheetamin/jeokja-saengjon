# 개인 Gmail 연결 — 0.1.2

이 버전부터 `Google 계정 종류 → 개인 Gmail (@gmail.com)`을 명시적으로 선택할 수 있습니다.
학교 Workspace 모드는 기존의 조직 계정 확인을 유지합니다. 어느 모드든 로그인한 계정이 저장한 이메일 주소와 정확히 일치하고 Google에서 인증한 주소여야 합니다.

## 앱에서
1. Google 계정 종류를 개인 Gmail로 선택합니다.
2. 연결할 Gmail 주소를 입력합니다.
3. 저장할 계정과 위치를 확인하고 확인란을 체크합니다. 실제 학생 자료는 소속 기관 지침을 먼저 확인하세요.
4. Google 연결 패널의 `연결 설정 저장`을 누릅니다.
5. 아래에서 준비한 데스크톱 OAuth JSON을 등록합니다.
6. Google 연결을 누르고 선택한 계정으로 로그인합니다.

개인 Gmail 선택만으로 Google OAuth 클라이언트가 자동 생성되지는 않습니다. 실제 Google 연결과 세 파일 저장은 계정 설정 후 확인해야 합니다.

## Google Cloud에서 한 번 준비
Google Cloud Console(https://console.cloud.google.com/apis/credentials)에서 진행합니다. 처음 표시되는 서비스 약관은 계정 소유자가 직접 읽고 동의 여부를 결정해야 합니다. 이 작업에는 유료 체험 가입이나 결제 계정 연결이 필요하지 않습니다.

1. 적자생존용 프로젝트를 선택하거나 새로 만듭니다. 기존 프로젝트와 계정은 변경하지 않아도 됩니다.
2. Google Sheets API와 Google Drive API를 사용 설정합니다.
3. Google Auth Platform의 앱 정보와 사용자 지원 이메일을 설정합니다.
4. 개인 Gmail은 외부 사용자 유형으로 설정합니다. 시험 상태에서는 연결할 본인 Gmail을 테스트 사용자로 추가합니다.
5. OAuth 클라이언트 유형을 데스크톱 앱으로 생성하고 JSON을 내려받습니다.
6. 이 JSON을 적자생존 앱에서 등록합니다. JSON·토큰은 공개 GitHub나 채팅에 올리지 마세요.

계정 등록과 권한 승인은 개인 Google 계정 소유자가 해야 합니다. 이 앱은 이메일 내용이나 전체 Drive에 접근하는 범위를 요청하지 않습니다. 요청하는 것은 로그인 확인(openid/email)과 앱에서 생성한 파일을 관리하는 drive.file 범위입니다.

테스트 상태, 사용자 제한, 동의 화면 설정이나 토큰 만료 때문에 다시 로그인이 필요할 수 있습니다. 실제 오류 문구에 따라 Google Cloud 설정을 확인하세요.

## 자료 보호와 검증 범위
개인 계정 연결 허용은 개인정보 처리 적합성 승인과 다릅니다. 최초에는 가상 자료로 시험합니다. 계정 선택·설정 저장과 허용/거부 분기는 자동 테스트로 확인하지만 실제 계정의 Google 로그인과 파일 전송을 완료한 것으로 표시하지 않습니다.
