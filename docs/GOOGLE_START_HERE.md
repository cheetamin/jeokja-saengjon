# Google 연결, 처음 시작하기

Google 연결은 선택입니다. 연결하지 않아도 내 컴퓨터에서 상담을 기록할 수 있습니다. 처음에는 가상 학생으로 시험하세요. 실제 학생 자료를 저장하기 전에는 학교의 계정·저장 환경 지침을 확인하세요.

## 1. 내 계정 저장
앱의 설정 → Google Sheets 3종 연결에서 계정 종류와 본인 이메일을 입력합니다. 개인 Gmail이면 ‘개인 Gmail’을 선택합니다. 저장 위치 확인란을 확인한 뒤 **연결 설정 저장**을 누릅니다.

## 2. 앱에서 ‘Google 연결 시작 · 쉬운 안내’ 누르기
처음 한 번은 Google에서 인증 파일을 준비해야 합니다. 앱의 도우미에 아래 버튼들이 있습니다. 프로젝트 ID를 알면 입력하고, 모르면 빈칸으로 두고 Google 화면에서 같은 프로젝트를 선택하세요.

1. **Google 프로젝트 만들기 열기**: 본인 계정으로 적자생존용 프로젝트를 만듭니다. 서비스 약관은 직접 확인합니다. 유료 체험·결제 계정을 만들 필요는 없습니다.
2. **Google Sheets API 열기**, **Google Drive API 열기**: 같은 프로젝트에서 각각 ‘사용’을 누릅니다.
3. **앱 정보 설정 열기**: 시작하기 → 앱 이름과 본인 지원·연락 이메일 입력. 개인 Gmail은 외부를 선택합니다. 마지막 사용자 데이터 정책을 직접 확인합니다.
4. **테스트 사용자 설정 열기**: 외부·테스트 상태라면 본인 이메일을 테스트 사용자에 추가하고 저장합니다. 학교 계정의 조직 제한은 관리자에게 확인하세요.
5. **Google 클라이언트 설정 열기**: 클라이언트 만들기 → 유형은 **데스크톱 앱** → 이름 입력 → 만들기. **새 창을 닫기 전에 JSON 다운로드**를 누릅니다.

## 3. 내려받은 파일 등록
앱의 **내려받은 JSON 선택** 또는 **OAuth JSON 등록**을 누릅니다. 다운로드 폴더의 `client_secret_…json` 파일을 고르세요. ‘등록됨’으로 바뀌면 준비된 것입니다. 파일 내용이나 비밀번호를 직접 입력하지 않습니다. 인증 파일을 다른 선생님·채팅·공개 저장소에 공유하지 마세요. 파일 선택을 취소하면 기존 등록은 유지됩니다.

## 4. Google 로그인
**Google 연결**을 누르면 브라우저가 열립니다. 앱에 저장한 본인 이메일과 같은 계정을 골라 권한을 확인하고, 완료되면 앱으로 돌아옵니다. 로그인 탭을 닫아 버렸다면 앱의 **로그인 취소 · 다시 준비하기**를 누른 뒤 다시 연결하세요. 앱을 강제로 종료할 필요는 없습니다.

## 5. 진짜 저장됐는지 확인
로그인 성공과 상담 전송 완료는 다릅니다. 가상 학생으로 상담 한 건을 저장하고 **기록별 동기화 상태 확인**을 누르세요. 개인정보 포함 파일은 저장 후, 가명 파일은 비식별 검토 승인 후, 나이스용 파일은 필수 분류 확인 후 동기화됩니다. 파일이 생성되면 앱에 각각 열기 버튼이 나타납니다.

## 자주 막히는 부분
| 보이는 상황 | 할 일 |
|---|---|
| Google 연결 버튼이 회색 | 계정·확인란을 저장했는지, JSON이 등록됐는지 확인 |
| JSON 파일이 없음 | 발급 창이 열려 있으면 JSON 다운로드. 이미 닫았다면 클라이언트 상세에서 보안 비밀번호 추가가 필요할 수 있음. 기존 키를 임의 삭제하지 않기 |
| JSON을 등록할 수 없음 | 웹 앱·서비스 계정 대신 데스크톱 앱 JSON인지 확인 |
| 403, access_denied, 테스트 사용자 오류 | 같은 프로젝트에 본인 이메일이 테스트 사용자로 등록돼 있는지, 학교 관리자 제한이 있는지 확인 |
| 계정이 다르다는 오류 | 앱에 저장한 이메일과 브라우저에서 선택한 계정이 같은지 확인 |
| 로그인했는데 파일이 없음 | 가상 상담을 저장하고 각 대상의 동기화 상태 확인. 세 파일 모두 완료 전에는 전체 저장 완료로 보지 않기 |

이 도우미가 Google 설정이나 기관 승인을 대신하지 않습니다. 여러 선생님이 공통 배포 계정으로 로그인만 하는 방식은 별도 배포용 OAuth 구성과 검증이 필요합니다.

동의 화면: https://developers.google.com/workspace/guides/configure-oauth-consent?hl=ko
